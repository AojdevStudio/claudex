### Added

- configure model context windows (#10)

### Changed

- Bump toml from 0.9.12+spec-1.1.0 to 1.1.4+spec-1.1.0 (#4)

- preserve the protected test gate (#6)
- publish without repository checkout (#5)

### Added

- Ship the initial Rust launcher with alias-only model selection, explicit raw-model routing, diagnostics, completions, and secure local configuration (#1).

### Fixed

- Close pre-release security and contract gaps found by independent standards and specification reviews.
